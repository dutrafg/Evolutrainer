Dados e segurança
📁 Organização do banco de dados

Na pasta-base escolhida, o catálogo compartilhado fica separado dos registros particulares de cada cliente. A estrutura antiga alunos/ continua legível por compatibilidade.

Banco de dados/
├── biblioteca/exercicios.json
├── clientes/indice.json
└── clientes/NOME--ID/
    ├── cliente.json
    ├── rotinas.json
    ├── sessoes.json
    ├── evolucao.json
    └── perfil.json
🔒 Trava de atendimento

Verificando sessão...

Uma sessão em andamento impede trocar de cliente ou iniciar outra. A liberação acontece somente após registrar e confirmar o salvamento da sessão no banco e na pasta.

💾 Backup completo e restauração

Crie um JSON com os perfis, treinos, sessões, avaliações e catálogo. Para restaurar, selecione a pasta-base correta. A restauração exige confirmação explícita e inclui uma cópia de segurança dos dados atuais.

👤 Backup individual

Escolha o cliente do backup individual. O JSON inclui exercícios utilizados nos treinos e incorpora imagens/GIFs disponíveis para restauração em outro aparelho, sem misturar dados de outros clientes. Arquivos grandes podem levar mais tempo.

🖼️ Qualidade das miniaturas

O catálogo base inclui 1.230 miniaturas visíveis. Algumas são fotografias ou animações verificadas; outras são ilustrações do grupo muscular, identificadas como não instrutivas. A importação de mídias com direitos de terceiros exige autorização.

📦 Transferir cliente entre dispositivos

Exporte um pacote portátil com cadastro, rotinas, séries, treinos concluídos, evolução, medidas e exercícios personalizados. No celular, importe o arquivo no mesmo EvoluTrainer: o cliente será criado ou atualizado pelo seu identificador, sem misturar outros perfis.

A transferência não envia dados para nenhum servidor. Compartilhe este arquivo apenas por um meio seguro.

🕙 Backup diário de treinos — 22h

Todos os dias, às 22h do dispositivo, salva os treinos, sessões e dados dos clientes. Com uma pasta autorizada, cria backups/diarios/. Sem pasta, mantém cópia no armazenamento local do navegador, que pode ser baixada manualmente.

Carregando informações do backup...

O backup automático requer o aplicativo aberto. Se ele estava fechado às 22h, a rotina pendente será executada na próxima abertura. A cópia no navegador não substitui um backup externo.

🛡️ Integridade e privacidade

Os arquivos JSON na pasta não são criptografados. Proteja seu dispositivo e faça backups regulares. Firefox e alguns navegadores não permitem escolher uma pasta física.
