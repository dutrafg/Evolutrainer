EVOLUTRAINER v6.0 PT-BR — VERCEL/PWA ESTÁTICO

1) Extraia todo o ZIP, mantendo as pastas.
2) Publique o conteúdo da pasta raiz (index.html e vercel.json) na Vercel como site estático (Framework Preset: Other; Build Command: vazio; Output Directory: padrão/raiz).
3) Abra o domínio HTTPS. O Service Worker/manifesto instala o núcleo do app para uso offline.
4) Em Configurações > PWA e biblioteca offline, clique em “Baixar biblioteca completa para uso offline” para salvar todas as mídias neste aparelho (espaço/quota variáveis).
5) Para usar com clientes já cadastrados no HTML local, exporte os dados pelo backup e importe no domínio da Vercel. Por segurança, o IndexedDB não migra automaticamente entre origens.
6) É obrigatório usar backup externo frequente. Dados financeiros e de clientes continuam locais neste navegador; a Vercel hospeda apenas o código público e as imagens.

ATENÇÃO:
- HTTPS/localhost é necessário para Service Worker. file:// não instala PWA.
- A primeira visita requer internet para baixar o núcleo. Para mídia totalmente offline execute o download completo; se o navegador eliminar cache por falta de espaço, refaça o download.
- Para o modo Aluno em dispositivos compartilhados, a seleção de perfil não é autenticação segura.
- O aplicativo não processa pagamentos reais: Cobranças registra lançamentos manuais.
- Navegadores que não oferecem File System Access só armazenam no IndexedDB; a pasta física não é garantida.
- O backup automático às 22h exige que o app esteja aberto; ao reabrir, verifica pendências.

Arquitetura:
index.html — interface da SPA
assets/css/ — CSS modular em ordem de cascata
assets/js/ — JS separado em módulos de funções, em ordem de execução original
data/exercises.json — catálogo de 1.230 exercícios
media/thumbs, media/steps — 2.947 imagens e animações
assets/anatomia-corporal.svg — arte utilizada no mapa corporal
manifest.webmanifest — metadados de instalação
sw.js — cache da interface e mídias sob demanda
vercel.json — configuração estática e cache HTTP

OBS: os arquivos JS foram separados por função para manutenção, preservando o escopo compartilhado do código original; ainda não usam imports ES Modules. Isso reduz o risco de regressão no banco e nos treinos.
